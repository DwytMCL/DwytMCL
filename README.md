# Hi, I'm Dwight

I'm a Computer Engineering student at **Mapúa Malayan Colleges Laguna**, exploring different areas of technology and engineering through hands-on projects. This portfolio brings together the applications, tools, and experiments I build as I learn.

## AI agent tools

MCP servers that let Claude and other AI agents use real websites through your own signed-in browser, with no API keys. They find page elements by accessible role and name, so they keep working when a site's layout changes.

| Project | What it does |
| --- | --- |
| [anysite-mcp](https://github.com/DwytMCL/anysite-mcp) | Turns any website into MCP tools, and saves completed tasks as reusable shortcuts. On npm as [`anysite-mcp`](https://www.npmjs.com/package/anysite-mcp). |
| [notebooklm-mcp](https://github.com/DwytMCL/notebooklm-mcp) | Lets Claude use Google NotebookLM with a free account. On npm as [`notebooklm-browser-mcp`](https://www.npmjs.com/package/notebooklm-browser-mcp). |
| [gemini-mcp](https://github.com/DwytMCL/gemini-mcp) | Lets Claude use the Google Gemini web app with a normal Google account. |

I also wrote launchers that connect Claude to two macOS creative apps through their built-in MCP servers:

| Project | What it does |
| --- | --- |
| [filmcraft-mcp](https://github.com/DwytMCL/filmcraft-mcp) | Lets Claude drive the FilmCraft video editor: sync audio, make cuts, move clips, mix and export. |
| [effectcraft-mcp](https://github.com/DwytMCL/effectcraft-mcp) | Lets Claude build compositions and render previews in the EffectCraft motion graphics app. |
